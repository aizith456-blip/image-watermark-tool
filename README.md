# 图片批量加文字水印工具

这是一个简单易用的在线图片批量加文字水印工具。所有图片处理都在您的浏览器本地完成，无需上传到服务器，保障您的隐私和数据安全。

## 功能特性

-   **批量上传图片：** 支持一次性选择多张图片进行处理。
-   **自定义水印文字：** 自由输入您想添加的文字。
-   **丰富的样式设置：**
    -   字体选择 (Arial, 微软雅黑, 宋体等)
    -   字号大小调整
    -   颜色选择
    -   透明度调整
    -   多种位置选择 (左上、居中、右下、平铺等)
    -   水印旋转角度
-   **实时预览：** 立即查看水印效果。
-   **批量下载：** 处理完成后，所有带水印的图片将自动打包成 ZIP 文件下载。
-   **隐私保护：** 图片处理完全在客户端浏览器进行，不会上传到任何服务器。

## 如何使用

1.  **访问工具：** [点击这里访问在线工具][(https://aizith456-blip.github.io/image-watermark-tool/)
    (请将 `YOUR_USERNAME` 替换为你的 GitHub 用户名，将 `YOUR_REPOSITORY_NAME` 替换为你的仓库名)
2.  **选择图片：** 点击“选择文件”按钮或将图片文件拖拽到指定区域。
3.  **配置水印：** 在“配置水印”区域，输入水印文字，并调整字体、字号、颜色、透明度、位置和旋转角度。
4.  **实时预览：** 在“预览效果”区域查看第一张图片的实时水印效果。
5.  **开始处理：** 点击“开始处理图片”按钮。
6.  **下载结果：** 处理完成后，点击“下载所有水印图片 (.zip)”按钮，即可下载打包好的图片。

## 本地部署 (可选)

如果您希望在本地运行此工具，只需将 `index.html` 文件下载到您的电脑，然后用浏览器打开即可。

## 技术栈

-   HTML5
-   CSS3
-   JavaScript (Canvas API)
-   [FileSaver.js](https://github.com/eligrey/FileSaver.js/) (用于保存文件)
-   [JSZip](https://stuk.github.io/jszip/) (用于打包ZIP文件)
